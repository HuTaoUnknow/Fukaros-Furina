## v0.4.11 — 2026-10-12

本次汇总自 v0.4.4 之后的本地更新，配套提供 **Fukaros 0.4.10（Windows x64）** 与 **Furina 0.4.11（Android ARM64）**。两端继续使用同一配对和投屏协议，版本号不同也可配套使用。

### 移动端全屏

- 删除 Qt 全屏退出按钮及硬件视频层上的原生退出按钮，避免遮挡投屏内容。
- 使用 Android 系统的屏幕边缘返回手势或返回键恢复普通界面，保持投屏连接和视频播放。
- 取消自定义的画面内左滑识别，普通滑动不会退出全屏。

### 双端界面和设置

- 电脑端用分割线区分方向、复制 / 扩展和清晰度，与横屏手机、平板布局保持一致。
- 电脑端仅保留系统标题栏的一套窗口按钮。关闭窗口进入托盘，继续连接和投屏；托盘菜单支持恢复窗口和退出应用。
- 电脑端使用一根呆毛图标，移动端使用三根呆毛图标，原图外围白色区域裁为透明。
- 设置区将连接必填项与可选 / 调试项分开，使用较暗的绿色、黄色背景。配对码、平板导航和远程控制保持普通背景。
- 说明步骤收进“…”按钮，两端统一点击查看、再次点击关闭。按钮背景透明、高度减半，使用上方竖向弹簧保持靠下布局；悬停不自动弹出。
- 移动端设置可在内容区域用手指上下滑动，保存 / 取消按钮固定在底部。较长帮助内容也可滚动。
- 扩展位置弹窗说明正文使用 11px、步骤标题使用 12px，并支持说明换行。

### 连接和停止

- 默认有线连接改为 USB 网络共享：通过 USB 网卡自动发现和连接，不依赖 USB 调试、Wi-Fi 或外网。仍需在平板系统设置中开启 USB 网络共享；仅充电或文件传输模式不能投屏。
- 保留 ADB 兼容模式，供不支持 USB 网络共享的设备或开发调试使用。
- USB 模式只在 USB 网卡及对应网段发现目标，支持指定 USB IP、多设备识别和取消发现；不会自动切换到 Wi-Fi。
- 任意一端点击停止后，两端同步结束当前投屏、清空画面、解除方向和模式锁定。重新开始仍需对端同意。
- 等待对端同意时保持转圈，得到同意并开始会话后才显示停止图标。

### 扩展屏位置

- 删除设置中的“电脑分享”和显示器选择区域：复制自动采集主屏，扩展自动采集平板对应的虚拟屏。
- 首次扩展连接在对端同意、虚拟屏就绪后打开 Windows 显示设置。调整屏幕位置并应用，返回点击“完成并记住位置”后开始投屏。
- 后续连接可选择“继承之前屏幕位置”或“重新配置屏幕位置”，保存的位置支持电脑屏幕左侧、上方等负坐标。
- 位置不适合当前显示器布局时转入重新配置。等待配置期间可以停止或取消，迟到回调不会重新启动视频发送。

### 安装与验证

Windows 安装包包含 Qt 运行库、必要插件、FFmpeg、独立 ADB 和签名虚拟显示驱动文件，新电脑无需 Qt 开发环境或模拟器。扩展功能首次安装驱动时需要管理员权限。移动端 APK 沿用既有测试签名，支持覆盖旧预览版。

发布页包含双端安装包、`SHA256SUMS.txt` 和 `UPDATE-0.4.11.md`。视频目标仍为 60 FPS，实际结果受硬件、分辨率和网络影响。回归及真机验证范围见 [发布验证](VALIDATION.md)。
