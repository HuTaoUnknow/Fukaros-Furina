# Fukaros + Furina v0.4.18

发布日期：2026-10-18。电脑端 **Fukaros 0.4.18** 与移动端 **Furina 0.4.18** 配套发布，Android 内部版本号为 22。本次汇总 v0.4.14 之后的本地改进，沿用预览版发布方式。请同时更新两端，以使用新增的鼠标与全屏状态协议。

## 主要更新

### 独立鼠标与副屏速率

- 通用设置新增默认勾选的“独立映射鼠标”：视频与鼠标分别传输，鼠标位置和图案不必等待视频解码；关闭后沿用鼠标与画面合成的兼容模式。
- 独立通道复用既有端口和 USB ADB 转发，并使用会话派生的认证密钥。位置积压时保留最新位置，通道不可用时回退到视频合成。
- 副屏鼠标速率以主屏速率的倍率表示，可调范围 0.25–4 倍，双端同步保存；主屏系统鼠标速率保持不变。
- 修正竖屏扩展的采集方向，支持 1200×1920 的实际竖屏桌面。

### 投屏结束与应用启动

- 无论哪一端停止、断线或取消扩展，电脑都会移除当前虚拟扩展屏，避免鼠标继续进入已停止显示的左侧桌面。已保存的屏幕位置仍可用于下次连接。
- 电脑端加入单实例保护；重复打开快捷方式会唤起已有窗口，包括最小化和托盘状态。
- 安卓端修复系统返回手势，返回时依次关闭设置、还原全屏、返回桌面。回到桌面不等于结束投屏，返回应用后重新绑定视频表面并恢复画面。
- 已批准的投屏会话使用前台服务保持连接，通知提供返回应用和停止投屏入口；停止或断线后结束服务。

### 延迟与状态同步

- 移除安卓接收端固定的 50 毫秒播放缓冲；解码完成后尽快呈现，积压时优先显示最新的已解码画面，同时保留压缩参考帧的解码顺序。
- 明确电脑解码的帧内切片线程策略，并在 TCP 建连后设置低延迟选项。
- 安卓本地放大、系统返回退出全屏，以及电脑发起的远程操作，均由接收端回传实际状态。电脑端按钮在收到确认后切换，避免两端图标不一致。
- 加入重复请求确认、快速连续操作、超时提示和会话结束后的状态复位，避免确认消息循环触发操作。

## 安装包

| 文件 | 适用平台 |
| --- | --- |
| `Fukaros-0.4.18-windows-x64-setup.exe` | Windows 10 / 11 x64，包含所需运行库和虚拟显示驱动文件；无需安装 Qt 或模拟器。 |
| `Furina-0.4.18-android-arm64.apk` | Android 9 及以上 ARM64，沿用原包名和测试签名，支持覆盖安装。 |
| `SHA256SUMS.txt` | 双端安装包的 SHA-256 校验值。 |
| `UPDATE-0.4.18.md` | 本次更新说明。 |

覆盖安装保留原连接和鼠标设置。USB 网络模式仍需在移动端开启 USB 网络共享；ADB 兼容模式仍需 USB 调试。首次安装扩展屏驱动时需要管理员授权。

## 验证与使用范围

- 电脑端 17 / 17、移动端桌面模拟 3 / 3 自动测试通过。
- Windows 真机验证正常创建、连接前已有虚拟屏以及左侧布局的停止清理，物理显示器配置保持不变。
- Android 15 平板验证后台返回、全屏请求确认、本地放大与系统边缘返回的状态回传，停止后虚拟屏已移除。
- 视频仍以 60 FPS 为目标，稳定真机采样约为 59–60 FPS；切换和网络波动时可能下降。移除 50 毫秒软件缓冲不代表端到端延迟实测降低相同数值。

完整验证范围见 [发布验证](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.18/docs/VALIDATION.md)。
