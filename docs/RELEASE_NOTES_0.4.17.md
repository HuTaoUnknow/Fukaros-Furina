# Fukaros / Furina 0.4.17

双端版本统一为 0.4.17，Android versionCode 为 21。相关改动已纳入 [v0.4.18 公开发布](UPDATE-0.4.18.md)。

## 停止投屏与重复启动

- 任一端结束会话、连接断开或取消扩展连接时，电脑移除 Furina 虚拟扩展屏。即使虚拟屏在连接前已经存在，也不会恢复包含该虚拟屏的旧拓扑，避免鼠标进入已停止显示的左侧桌面。
- 根据当前显示拓扑移除虚拟目标，保留物理显示器配置。显示配置暂时忙碌时进行有限次数重试；扩展屏位置仍由原位置设置单独保存。
- 电脑端在创建界面和显示控制器前取得用户实例锁。再次打开快捷方式或其他目录下的 Fukaros 会唤起已有窗口，包括最小化和托盘状态。崩溃后可恢复实例锁；已有实例无响应时不会启动第二个投屏实例。

## 视频延迟

- 平板接收实时桌面时，移除固定的 50 毫秒播放时间线，解码完成后提交到下一次屏幕刷新。解码输出已经积压时，只显示最新的已解码画面；仍按顺序解码压缩参考帧。
- 电脑解码显式使用帧内切片线程，避免帧级线程引入额外等待。在本机对照测试中旧配置已经选择切片线程，两种配置均在首个输入包产生画面，不声称此项在本机额外减少了一帧延迟。
- 主 TCP 连接建立后设置低延迟选项，覆盖主动连接尚未创建底层套接字的情况。保留原有背压、关键帧恢复和画质策略。
- 50 毫秒为移除的软件固定缓冲，不是端到端延迟实测改善值。网络、采集、编码、解码和屏幕刷新仍影响实际延迟。

## Android 返回与后台恢复

- 接入 Android 系统返回回调，并兼容传统返回键。返回操作先关闭设置或退出全屏，再返回桌面并保留投屏会话。
- 获得对端同意后启动设备连接前台服务，提供返回应用和停止投屏的通知入口；停止、取消或断线后结束服务。
- 显示表面销毁后不再向旧表面持续送帧；返回应用后重新绑定表面并请求关键帧。回到桌面不等同于结束投屏。

## 验证

- 电脑端自动测试 17 项通过；移动端桌面模拟测试 3 项通过，包含返回设置、退出全屏、后台状态恢复、保留会话和停止通知回调。
- Windows 真机显示测试覆盖正常创建和连接前已有虚拟屏两种情况：释放后虚拟屏均已移除，物理显示器配置不变。
- Android 安装包沿用原签名证书并通过签名、16 KB 对齐检查。
- Android 15 平板（23046RP50C）真机验证：1200×1920 扩展会话在主页及返回桌面手势后保持连接，返回应用恢复画面；全屏返回先还原界面。移动端停止后，核心测试正常结束并移除虚拟屏（5759 个编码包、22 次接收反馈，释放返回值 0）。稳定采样显示约 59–60 帧/秒，切换和网络抖动时会下降；不保证始终 60 帧/秒。

安装包：`Fukaros-0.4.17-windows-x64-setup.exe`、`Furina-0.4.17-android-arm64.apk`。
