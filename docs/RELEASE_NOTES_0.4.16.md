# 0.4.16 本地更新

Fukaros、Furina版本统一为0.4.16，Android内部版本号20。

- 配对码下面的“分屏鼠标速率”分组改为“通用设置”，保留副屏为主屏多少倍的调速方式。
- 新增默认勾选的“独立映射鼠标”，支持投屏期间切换、即时保存和双端同步。
- 勾选后，独立连接发送鼠标位置和图案，移动端在视频上方绘制鼠标；取消后沿用鼠标合成进视频的兼容方式。
- 为虚拟副屏增加Windows Graphics Capture无鼠标采集路径，保留GPU缩放及硬件编码；独立通道不可用时回退兼容方式。
- 切换时重建编码资源，接收端按实际呈现帧切换光标，避免重复显示。解码器恢复时保留独立光标，绘制等待不阻塞视频接收。
- 特殊反色光标在独立模式使用黑白轮廓。此选项用于电脑向移动端投屏，双端需要匹配版本。

验证：电脑16项、移动模拟3项回归通过；独立连接鉴权、视频积压下的位置传输、双向设置同步通过。真实1200×1920 GPU采集/编码/解码四角图样250帧全部正确；真机验证两种方式切换。鼠标端到端延迟尚未进行毫秒级量测。

本版本仅在本地更新，尚未同步GitHub。
