# Fukaros / Furina 0.4.18

双端版本统一为 0.4.18，Android versionCode 为 22。相关改动已纳入 [v0.4.18 公开发布](UPDATE-0.4.18.md)。

- 修复安卓端本地放大、还原后，电脑端放大按钮仍显示旧状态的问题。通过系统返回手势、返回键退出全屏，同样会同步。
- 全屏请求仍使用 `FR_MAXIMIZE=5`、`FR_RESTORE=6`；接收端回传 `FR_FULLSCREEN_CONFIRMED=10` 或 `FR_RESTORED_CONFIRMED=11` 表示当前实际界面状态。确认消息只更新发送端按钮，不会再次触发全屏命令。
- 电脑端发起远程全屏操作后，按钮保持最近一次确认的状态，收到接收端确认再变更。重复请求仍会获得确认；快速连续点击会交替发送进入/退出请求。
- 状态仅在已获同意的投屏会话中接受，断线或停止后复位，忽略无活动会话和错误方向的确认。等待确认超时会写入调试信息，不推测远端状态。
- 核心逻辑放在双端 `core/presentation_sync.*`，同时支持反向投屏时的状态同步。

验证：电脑端 17 项自动测试、移动端 3 项自动测试通过。新增覆盖远端主动变化、请求等待确认、连续操作、重复还原确认、无会话状态忽略、安卓返回退出全屏的状态回传。

Android 15 平板真机验证：远程请求进入/还原全屏往返成功；安卓本地放大后使用返回键、边缘返回手势均收到对应的 10 / 11 确认。测试会话正常停止并移除虚拟屏，释放返回值为 0。

安装包：`Fukaros-0.4.18-windows-x64-setup.exe`、`Furina-0.4.18-android-arm64.apk`。协议有新增状态值，请配套更新两端。
