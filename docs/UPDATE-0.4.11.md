# Fukaros + Furina v0.4.11

本次汇总 v0.4.4 之后的更新，配套应用为 **电脑端 Fukaros 0.4.10** 和 **移动端 Furina 0.4.11**。两端版本号不同，但使用同一投屏协议，可配套安装。

## 本次变化

- **全屏更简洁**：移动端移除退出全屏按钮，使用 Android 系统屏幕边缘返回手势或返回键退出；普通画面左滑不会退出，投屏继续播放。
- **双端设置统一**：必填 / 可选连接项分区并采用深色背景；配对码、导航和远程控制保持普通背景。透明半高“…”按钮点击后才显示步骤，移动端支持内容区域触控滚动。
- **扩展屏位置记忆**：首次扩展自动打开 Windows 显示设置，调整并确认后开始投屏；下次可继承之前位置或重新配置。
- **免调试 USB 模式**：通过系统 USB 网络共享形成 USB 网卡，自动发现平板；保留 ADB 兼容模式。仅插线、充电或文件传输模式仍不能投屏。
- **双端停止同步**：任意一端停止后，两端清空画面、恢复开始并解除方向和模式锁定；等待同意时保持转圈。
- **电脑托盘与图标**：关闭电脑窗口进入托盘并保持投屏，菜单可恢复或退出；电脑端一根呆毛、移动端三根呆毛图标，外围背景透明。

## 开始使用

1. 安装两端应用，设置相同的配对码。
2. 有线连接：插好数据线，在平板系统开启 **USB 网络共享**；两端选择 USB，电脑选择 USB 网络，USB IP 通常留空自动发现。无线连接：两端连接可互访的局域网，电脑填写平板 Wi-Fi IP。
3. 平板按开始启动服务，电脑选择投屏方向及复制 / 扩展后按开始，对端点击同意后投屏。
4. 扩展模式首次使用可能需要管理员权限安装驱动；在系统显示设置调整位置、应用并返回确认。之后可继承位置或重新配置。
5. 投屏期间仅清晰度可调整；需要更换方向、复制 / 扩展或连接参数时先停止。移动端放大后使用系统返回手势退出全屏。

## 验证与范围

两端 Release 构建与 **17 / 17 项 CTest 回归通过**；APK 签名和 16KiB 对齐检查通过。平板硬件视频实测确认普通左滑保持全屏、系统边缘返回恢复界面且投屏不中断。完整回归范围见仓库 [发布验证](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.11/docs/VALIDATION.md)，累计变化见 [更新记录](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.11/docs/CHANGELOG.md)。

这是沿用既有签名的预览发布。视频目标为 60 FPS，实际结果受设备和网络影响；USB 网络的发现和绑定已有回归覆盖，关闭 USB 调试后的真机网络共享投屏尚未完成实测。
