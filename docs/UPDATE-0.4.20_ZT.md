# v0.4.20_ZT：双端底部面板收纳

基于 v0.4.20（含 Windows 标题栏恢复修复），分支 `v0.4.20_ZT`。

- Fukaros_ZT 和 Furina_ZT 在设置按钮上方增加收纳按钮。横屏位于左侧工具栏，平板竖屏时随既有工具栏移到顶部、紧邻设置按钮之前。
- 底部“投屏方向”和“调试信息”展开时，按钮显示向下尖号；点击收起后显示向上尖号，再点展开。
- 收起整个底部区域，投屏画面自动占用腾出的空间。平板竖屏同时隐藏“投屏／调试”分页，并解除预览高度限制。
- 横竖屏切换、放大及退出全屏保留收纳状态。收纳只改变界面可见性，不停止投屏、不修改方向、分辨率或连接参数。
- 新的投屏确认请求到达时自动展开面板，使同意／拒绝按钮可见。
- 版本显示为 0.4.20_ZT，应用显示名称为 Fukaros_ZT / Furina_ZT。保留稳定版的应用身份、设置路径和 Android 签名，可覆盖安装并沿用原设置；二者不是并排安装包。
- 本分支不合并到 main，不覆盖 v0.4.20 稳定版的 GitHub 发布资产。

安装包：`Fukaros-0.4.20_ZT-windows-x64-setup.exe`、`Furina-0.4.20_ZT-android-arm64.apk`。
