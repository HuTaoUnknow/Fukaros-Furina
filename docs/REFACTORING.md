# 模块与目录重构记录

本次整理基于已发布的 0.4.18，保持功能、消息编号、设置键、Android 包名和界面布局不变。重构随 0.4.19 稳定版发布，旧标签和历史安装包保留。

## 完成内容

- 双端相同的协议、连接、会话、鼠标设置、日志和视频实现合并为公共 `core/`，不再维护两份副本。
- 共用画面控件、设置滚动、主题、图标和全屏呈现集中到公共 `ui/`；电脑退出按钮与移动系统返回通过明确策略区分。
- 第三方目录合并为一份 `third_party/`，878 个文件的内容逐一核对，保持字节不变。
- 主窗口拆分为界面装配、设置、会话与视频四个实现文件，构造函数保留原信号连接与初始化顺序。
- Windows 视频后端独立划分 GPU 采集、NVENC、Media Foundation 和 H.264 解码，工作线程不再包含全部平台实现。
- 使用公共 CMake 库表达依赖；增加仓库级桌面构建入口，保留两端单独配置与 Android APK 构建入口。
- 公共测试、平台单元测试和手动硬件检查分开；驱动、许可证和打包脚本路径随目录同步调整。
- 增加 `.clang-format`，统一自有 C / C++ / Java 代码格式，不格式化第三方源码。

## 验证

- 仓库级桌面 Release 构建完成；Fukaros 和 Furina 单独配置成功。
- 全部 20 项 CTest 回归通过。
- Android ARM64 APK 构建成功，JNI 桥接的 10 个原生导出入口仍存在。
- 原生 Windows NVENC 编码 / 解码画质检查通过，240 帧完整解码；软件解码首包输出检查通过。
- 画质检查需要原生 Windows 字体环境；在 offscreen 环境下，原版和重构版使用较小字体得到相同的既有阈值失败，已通过原版对照确认不是本次重构引入的问题。

目录职责和修改入口见 [代码结构](ARCHITECTURE.md)。
