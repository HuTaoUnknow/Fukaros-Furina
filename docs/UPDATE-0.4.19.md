# Fukaros + Furina v0.4.19 稳定版

发布日期：2026-10-19。Windows 电脑端 **Fukaros 0.4.19** 与 Android 移动端 **Furina 0.4.19** 配套发布，Android 内部版本号为 **23**。本版发布为稳定版，建议同时更新两端。

## 本次更新

- 整理双端代码结构：协议、传输、会话、设置、日志和视频实现集中到公共 `core/`，共享界面组件集中到 `ui/`，平台能力保留在各端目录。
- 主窗口按界面装配、设置、会话和视频拆分，Windows 视频后端按采集、编码和解码拆分，便于后续维护。
- 合并重复的第三方依赖，统一自有代码格式；新增根目录 CMake 构建入口，仍支持各端单独配置和 Android APK 构建。
- 补充 [代码结构与开发入口](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.19/docs/ARCHITECTURE.md)。本次保持投屏协议、设置键、Android 包名和界面布局兼容。

## 包含的投屏能力

- USB 网络 / ADB 兼容模式 / Wi-Fi 双向投屏，对端确认后连接；支持电脑桌面复制和扩展、移动端录屏与远程触控。
- 保留竖屏扩展、扩展位置记忆、独立鼠标传输、副屏鼠标倍率、停止后移除虚拟屏及电脑单实例 / 托盘功能。
- 保留移动端返回手势和后台恢复、低延迟播放及双端全屏状态确认。视频以 60 FPS 为目标，实际表现受设备与网络影响。

## 安装包

| 文件 | 适用平台 |
| --- | --- |
| `Fukaros-0.4.19-windows-x64-setup.exe` | Windows 10 / 11 x64，包含 Qt、FFmpeg、ADB 和虚拟显示驱动文件，无需预装 Qt 或模拟器。 |
| `Furina-0.4.19-android-arm64.apk` | Android 9 及以上 ARM64，沿用现有签名，可覆盖旧版。 |
| `SHA256SUMS.txt` | 双端安装包的 SHA-256 校验值。 |
| `UPDATE-0.4.19.md` | 本次更新说明。 |

覆盖安装保留已有设置。USB 网络模式需开启系统 USB 网络共享；ADB 兼容模式需开启 USB 调试；首次安装扩展屏驱动需管理员授权。

## 验证范围

- Windows Release 构建、双端共 20 项自动回归测试及 Android ARM64 Release APK 构建通过。
- 原生 Windows 编解码完成 240 帧，画质指标和首包输出达标；当前机器编码平均 17.25 毫秒，略超 60 FPS 单帧预算，未重构旧版对照为 17.19 毫秒。该性能门槛本轮未通过，未修改阈值。第三方依赖 878 个文件内容保持不变。
- APK 已校验签名、与旧版证书一致性及 16 KiB ZIP 对齐，安装包附带 SHA-256。
- 本次未重新执行平板安装及有线 / 无线完整真机流程；之前 v0.4.18 的真机验证记录保留在历史标签中。

详细范围见 [发布验证](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.19/docs/VALIDATION.md)。
