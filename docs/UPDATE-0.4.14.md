# Fukaros + Furina v0.4.14

发布日期：2026-10-12。电脑端 **Fukaros 0.4.14** 与移动端 **Furina 0.4.14** 统一版本号；后续配套发布继续保持一致。请同时更新两端，以使用本次新增的扩展方向协商。

## 本次更新

- 完成 Furina 竖屏布局：画面位于上方，下方左侧为开始 / 停止，右侧为设置和放大；使用“投屏模式 / 调试信息”复选项切换内容。横屏继续使用原布局。
- 竖屏接收扩展时，Windows 创建 1200×1920 的竖屏桌面；横屏为 1920×1200，均使用 60 Hz 显示模式。竖屏预览区域同步调整比例。
- 扩展获准后锁定移动端当前横竖屏；本端或对端停止后恢复原来的旋转策略。意外断线时需先点击停止释放锁定。
- 双端中文调试行统一参数名称与单位，例如帧率、分辨率、编码 / 解码耗时、队列和显示帧率；保留时间戳及对应英文行。
- 更新方向协商协议、方向锁定和竖屏界面回归测试。

## 安装包

| 文件 | 用途 |
| --- | --- |
| `Fukaros-0.4.14-windows-x64-setup.exe` | Windows 10 / 11 x64；包含 Qt、FFmpeg、独立 ADB 和扩展屏驱动文件，无需预装 Qt。 |
| `Furina-0.4.14-android-arm64.apk` | Android 9 及以上 ARM64；沿用现有包标识及测试签名，可覆盖安装。 |
| `SHA256SUMS.txt` | 两个安装包的 SHA-256 校验值。 |
| `UPDATE-0.4.14.md` | 本次更新说明。 |

覆盖安装保留原应用设置。APK 的内部构建号递增为 18，用户可见版本统一为 0.4.14。

## 竖屏扩展使用

1. 更新双端，将 Furina 转为需要的横屏或竖屏。
2. 选择获取电脑屏幕和扩展，建立连接，由对端同意；电脑发起时也以移动端接收时的方向为准。
3. 按既有流程继承屏幕位置，或打开 Windows 显示设置重新配置位置。
4. 扩展开始后方向保持锁定。需要改变方向时，点击停止、旋转设备，再开始扩展。

## 验证与边界

双端 Release 构建、自动回归、安装包内置版本以及 APK 签名 / 16KiB 对齐均经过检查。Windows 原生测试确认竖屏和横屏虚拟显示模式、负坐标位置及原显示布局恢复；Android 真机已验证两种方向的锁定和停止后恢复。

本次 Android 方向实测使用真实应用与认证协议测试端；本轮没有重新测量端到端视频帧率。60 Hz 是虚拟屏模式，视频仍以 60 FPS 为目标，实际结果受设备和网络影响。完整验证记录见 [发布验证](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.14/docs/VALIDATION.md)。
