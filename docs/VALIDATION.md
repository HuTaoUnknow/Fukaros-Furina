# v0.4.14 发布验证

验证日期：2026-10-12。双端版本统一为 **0.4.14**。

## 构建与包版本

- Fukaros：Qt 6.11.1 / MinGW 13.1，Windows x64 Release；应用版本、EXE 产品资源和安装程序版本均为 0.4.14。
- Furina：Qt 6.11.1 Android ARM64 / NDK r27c / JDK 21，Release APK；包名 `com.furina.black`，versionName 0.4.14，versionCode 18，最低 API 28、目标 API 35。
- APK 使用原有测试证书，通过签名、证书一致性和 16KiB zipalign 检查。密钥不进入仓库。
- Windows 安装包包含 Qt、FFmpeg、独立 ADB 和签名虚拟显示驱动文件。

## 自动回归

发布前重新执行 CTest：**Fukaros 14 / 14 通过，Furina 桌面模拟 3 / 3 通过，共 17 / 17 通过**。

新增覆盖：竖屏布局与模式 / 调试切换、中文参数转换、接收端方向协商、仅允许接收端调整方向标志、停止后解除方向锁定、意外断线后保持锁定直到停止。

通用界面测试使用 offscreen；需要真实虚拟屏的界面用例会跳过，托盘测试使用原生 Windows 平台。移动端桌面模拟不替代 Android 系统接口实测。

## 原生与真机验证

- Windows 原生虚拟屏：1920×1200 横屏与 1200×1920 竖屏均确认为 60 Hz，四轮左侧 / 上侧负坐标测试通过，实体屏设置及最终显示布局恢复。
- Android 真机：竖屏扩展期间施加横屏旋转请求，屏幕保持 1800×2880；停止后恢复 2880×1800。
- Android 真机：横屏扩展期间施加竖屏旋转请求，屏幕保持 2880×1800；停止后恢复 1800×2880。结束后恢复系统自动旋转。
- 真机方向验证使用此次代码逻辑对应的 Furina 0.4.13；本次 0.4.14 对功能代码没有额外修改，仅统一版本与发布文档，并重新构建回归。
