# v0.4.20 发布验证

同版本覆盖更新：2026-10-26。Fukaros 与 Furina 均为 **0.4.20**，Android versionCode **24**。

## 正式构建与安装

- 使用正式源码构建 Windows x64 Release 和 Android ARM64 Release，不包含本地临时鼠标观测代码。
- Windows 使用 Qt 6.11.1 / MinGW 13.1；安装包包含 Qt、FFmpeg、独立 ADB、虚拟显示驱动及许可文件。
- Android 使用 Qt 6.11.1 / NDK r27c / JDK 21，最低 API 28，目标 API 35；沿用既有签名证书，校验签名及 16 KiB ZIP 对齐。
- 按同版本覆盖发布，v0.4.20 标签更新至本次源码提交，替换同一发布页的双端安装包、更新说明与 SHA256SUMS.txt。版本号和发布链接不变。
- 本机与既有平板使用相同发布文件覆盖安装，保留应用数据；通过 Windows 程序及设备 APK 的 SHA-256 核对安装结果。

## 标题栏修复回归

- 原生 Windows 窗口测试在修复前复现标题栏缺失，修复后 6 个场景全部通过：普通／最大化窗口分别覆盖直接退出、最小化恢复、隐藏后恢复。每个场景重复全屏切换并分别用 Escape、退出全屏按钮还原。
- 检查实际 HWND 的标题栏、系统菜单、最小化、最大化和可缩放边框样式，同时检查窗口位置、最大化状态、侧栏与控件恢复。
- 双端现有界面回归 `ui`、`black_ui` 在正常权限环境中通过（4.58 秒、5.51 秒）。受限环境下的启动失败未计为通过。
- 界面回归使用 offscreen／本机回环；标题栏回归仅操作隔离的测试窗口，不连接真实设备或创建投屏会话。

## 历史结果与验证边界

- 2026-10-23 首次 v0.4.20 发布的 `protocol`、`peer`、`ui`、`black_ui`、`screen_scale` 五组回归通过；本次未将历史结果记为新一轮完整回归。
- 方向记忆覆盖分享／获取方向的窗口销毁重建、异常记录回退，以及安卓后台保存不接受连接设置的未保存编辑；恢复后仍需手动开始并取得对端同意。
