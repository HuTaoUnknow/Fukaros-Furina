# v0.4.19 稳定版发布验证

验证日期：2026-10-19。Fukaros 与 Furina 均为 **0.4.19**，Android versionCode **23**。

## 构建与包一致性

- Windows：Qt 6.11.1 / MinGW 13.1，x64 Release；程序、PE 产品资源和安装程序版本一致。
- Android：Qt 6.11.1 Android ARM64 / NDK r27c / JDK 21；最低 API 28、目标 API 35。
- APK 使用原有证书签名，检查签名、旧版证书一致性和 16 KiB ZIP 对齐；密钥不进入源码仓库。
- Windows 安装包包含 Qt、FFmpeg、独立 ADB、签名虚拟显示驱动及许可文件。

## 自动回归与原生检查

- 统一构建的 20 项 CTest 回归全部通过：包括协议认证、会话同意、停止、USB 网络发现、方向锁定、鼠标倍率及同步、独立鼠标通道、单实例、全屏状态确认等。
- 各端独立 CMake 入口保留；桌面模拟验证不替代 Android 系统接口实测。
- 原生 Windows NVENC 编码 / 解码：240 帧完整解码，关键帧最低 PSNR 34.46、普通帧最低 PSNR 34.78、最高 QP 22，画质指标达标；首包解码与切片线程检查通过。
- 性能检查未全部通过：当前机器新版本平均编码 17.25 毫秒，旧版二进制对照 17.19 毫秒，均超过测试的 16.67 毫秒预算，测试程序因此返回失败。重构验证时曾测得 4.77 毫秒；本次记录实际结果，不调整阈值，也不将历史较快样本作为本轮性能通过依据。
- 画质检查使用原生 Windows 字体环境。offscreen 的字体差异会触发原有阈值失败，原版对照已确认该环境差异并非重构引入。
- 重构合并的 878 个第三方依赖文件逐一核对，内容未修改；自有 C / C++ / Java 代码格式检查通过。

## 本次范围

本次主要发布模块与目录重构及统一构建，不改动消息编号、设置键、Android 包名或界面布局。当前未覆盖安装电脑或平板，也未重复完整有线 / 无线与真实屏幕布局操作。v0.4.18 的系统返回、后台恢复、全屏同步、竖屏采集及停止清理真机记录见 [历史发布验证](https://github.com/HuTaoUnknow/Fukaros-Furina/blob/v0.4.18/docs/VALIDATION.md)。

视频以 60 FPS 为目标；实际帧率和延迟受硬件、网络及负载影响，未声明新的端到端延迟测量结果。安装包校验值见同一 Release 的 `SHA256SUMS.txt`。
