## 真机和原生流程

- 平板设置内容上下滑动、点击“…”显示步骤及再次点击关闭均已验证。
- Android 硬件视频播放时，画面中央左滑保持全屏；屏幕边缘的系统返回手势恢复普通界面，视频和连接继续运行。Qt 和原生视频层均不再创建全屏退出按钮。
- Windows 原生扩展位置测试此前确认：负坐标位置可读写，实体屏幕设置保持不变；配置完成前不发送视频，完成后开始编码，再次连接可继承之前位置。
- 托盘功能此前完成真实 Windows 窗口关闭 / 恢复 / 退出检查，以及隐藏窗口期间等待确认和接收画面的检查。

## 验证范围

USB 网络模式的发现、指定网段、源地址绑定、多目标处理和取消使用隔离的 UDP / TCP 回归覆盖。本轮平板硬件视频实测通过 ADB 转发进行，不代表已经完成关闭 USB 调试后的 USB 网络共享真机实测。

视频目标为 60 FPS，实际帧率受设备、分辨率和网络影响；本次硬件视频实测确认全屏退出后播放继续，并持续收到解码和显示反馈。Windows 接收侧使用 FFmpeg / D3D11VA，Android 使用 MediaProjection 和 MediaCodec Surface 编解码。

安装包 SHA-256 校验值随 GitHub Release 提供；公开源码和发布附件不包含个人配对码、设备序列号、签名密钥或开发截图。
