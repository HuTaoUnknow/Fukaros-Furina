# v0.4.18 发布验证

验证日期：2026-10-18。Fukaros、Furina 均为 **0.4.18**，Android versionCode **22**。

## 构建与安装包

- Windows：Qt 6.11.1 / MinGW 13.1，x64 Release；应用、EXE 产品资源和安装程序版本一致。
- Android：Qt 6.11.1 Android ARM64 / NDK r27c / JDK 21；最低 API 28、目标 API 35。
- APK 沿用既有测试证书，通过签名验证、证书一致性和 16 KiB zipalign 检查。签名密钥不进入仓库。
- Windows 安装包包含 Qt、FFmpeg、独立 ADB 和签名虚拟显示驱动文件。两端已覆盖安装并核对版本；电脑端安装前后全部应用设置保持一致。

## 自动回归

**Fukaros 17 / 17、Furina 桌面模拟 3 / 3 通过，共 20 / 20 项。**

覆盖协议认证、会话同意与停止、USB 网络发现、方向锁定、鼠标速率和设置同步、独立通道认证与位置合并、单实例及崩溃恢复、全屏确认和返回恢复等。界面通用测试使用 offscreen，托盘测试使用原生 Windows 平台；桌面模拟不替代 Android 系统接口实测。

## 原生及真机验证

- 虚拟显示：横屏 1920×1200 / 60 Hz、竖屏 1200×1920 / 60 Hz。停止清理覆盖正常创建、连接前已经附加虚拟目标、左侧负坐标位置；虚拟目标移除后物理显示器配置不变。
- 竖屏采集：WGC + NVENC 与电脑解码链路的四角颜色标记验证通过，确认画面方向与尺寸。
- 独立鼠标：Android 真机完成独立模式、视频合成模式及恢复独立模式切换；鼠标通道与主视频连接独立。
- 后台恢复：Android 15 平板在主页停留后恢复同一会话，全屏返回及普通返回到桌面后均可恢复画面；移动端停止后核心测试正常结束，虚拟目标释放返回 0。
- 全屏状态：远程进入 / 还原请求往返成功；安卓本地放大、返回键及边缘返回手势分别回传 10 / 11 状态确认，停止后无残留虚拟屏。

## 性能范围

真机稳定采样约 59–60 FPS，切换、无线抖动或设备负载会降低帧率，不保证持续 60 FPS。删除固定 50 毫秒软件播放缓冲已经由源码和真机回归确认，尚未测得端到端延迟数值。电脑软件解码对照测试中，旧配置已自动选择切片线程，两种配置均在首个输入包产生画面，不声称在该机器额外减少一帧等待。

本次未重新开展关闭 USB 调试后的 USB 网络共享全流程实测；该模式仍沿用原有发现与传输实现。运行限制及第三方信息见 README 和第三方组件文档。
